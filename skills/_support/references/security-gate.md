# The security gate

**Triggers.** A diff is security-sensitive when its content touches the repository's security focus (with none, the security items in its review standards) or any of these: authentication and authorisation, tenancy and mass assignment, crypto, keys and signatures, input handling and injection, deserialisation, file paths, outbound requests, secrets, dependency manifests, CI workflows and actions, and agent config (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `REVIEW.md`, `.claude/rules/`, `settings*.json`, `.mcp.json`, `skills/`, `agents/`, `commands/`, `.github/copilot-instructions.md`, `.github/instructions/`, `.github/skills/`, `.agents/skills/`).

**The brief.** Give the white-hat agent the diff, that focus (or these defaults) and the triggers that matched. Tell it to say whether each Critical or High flaw predates the branch (reachable from the base or default branch; can't tell counts as yes), and to report only to you, writing nothing to GitHub, files or agent memory.
